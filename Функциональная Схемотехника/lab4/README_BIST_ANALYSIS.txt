===============================================================
  Анализ распределения операндов BIST - Инструкция
  Лабораторная работа №4
===============================================================

ФАЙЛЫ:
------
- bist_analysis.py - Python скрипт для анализа

ТРЕБОВАНИЯ:
----------
1. Python 3.x
2. Библиотеки:
   - numpy
   - matplotlib

УСТАНОВКА БИБЛИОТЕК:
--------------------
pip install numpy matplotlib

ЗАПУСК:
-------
python bist_analysis.py

или (если несколько версий Python):
python3 bist_analysis.py

РЕЗУЛЬТАТЫ:
----------
Скрипт создаст:
1. bist_distribution.png - 4 графика распределения
2. bist_validity_map.png - карта допустимых значений
3. Вывод в консоль:
   - Статистику операндов
   - Процент допустимых значений
   - Покрытие диапазона

ЧТО ПОКАЗЫВАЮТ ГРАФИКИ:
-----------------------
1. Гистограмма 'a' - распределение операнда a
2. Гистограмма 'b' - распределение операнда b  
3. 2D scatter - точки (a,b) в плоскости
4. Покрытие диапазона - какие значения 0-255 покрыты

ОБЛАСТЬ ДОПУСТИМЫХ ЗНАЧЕНИЙ:
----------------------------
Операнды допустимы если:
- b > 0 (иначе cbrt(0) = 0)
- a * cbrt(b) < 65536 (результат в 16 бит)

Все 256 пар от LFSR попадают в зелёную область.

ДЛЯ ОТЧЁТА:
-----------
Вставьте в отчёт:
1. График bist_distribution.png
2. График bist_validity_map.png
3. Процент из консольного вывода
